# 🧬 NGS Data Analysis on HPC
**Instructor:** Vidhya Jagannathan  
**Year:** 2026 (16–20 November)  
**Location:** University of Bern IBU cluster

This repository contains the exercises for the 2026 NGS course. This year the exercises follow one real case: Weimaraner puppies with a hopping gait, caused by a variant in *EFNB3* ([Schwarz et al. 2025, Movement Disorders](https://doi.org/10.1002/mds.30243)).
